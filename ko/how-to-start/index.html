Fomo 거래 시작하기

설치부터 할인이 적용된 첫 거래까지 6단계입니다. 계정도, 비밀번호도 필요 없습니다 — 지갑과 추천 코드만 있으면 됩니다.

  1. 1단계 — 앱 다운로드

    Fomo는 iOS, Android, Web 버전으로 제공됩니다. 공식 앱스토어 또는 fomo.family에서 직접 다운로드하세요 — 서드파티 APK는 피하는 것이 좋습니다.

  2. 2단계 — 계정 생성 및 복구 수단 백업

    가입 절차를 따라가면 기기에서 지갑이 생성됩니다. Fomo는 논커스터디얼이므로 지갑과 키가 Fomo가 아닌 본인 기기에서 생성·보호됩니다(Shamir's Secret Sharing 방식) — 앱이 제공하는 백업/복구 수단을 자금을 입금하기 전에 반드시 실행하세요.

  3. 3단계 — 추천 코드 입력

    가입 시 유효한 추천 코드를 입력하면 이후 모든 거래에 10% 수수료 할인이 적용됩니다.

  4. 4단계 — 자금 입금

    지역과 체인에 맞는 방식으로 입금하세요. Fomo는 Solana, Base, BNB Chain, Monad에서 작동합니다 — 반드시 올바른 네트워크로 전송했는지 확인하세요. 잘못된 체인으로 전송하는 것은 되돌릴 수 없는 대표적인 실수입니다.

  5. 5단계 — 첫 거래하기

    스팟 거래(밈코인, 알트코인, 스테이블코인)는 모든 사용자가 이용 가능합니다. 무기한 선물(Hyperliquid 연동)은 미국 외 지역에서 이용 가능합니다. 처음이라면 잘 이해하고 있는 자산으로 소액부터 시작하는 것을 권장합니다.

  6. 6단계 — 보안 기능 활성화

    잃으면 아쉬울 금액을 입금하기 전에 앱이 제공하는 모든 보안 옵션(생체 인증, 백업 확인 등)을 활성화하세요. Fomo는 문제가 생겨도 대신 개입할 수 없으므로, 본인의 보안 설정이 커스터디얼 거래소보다 훨씬 중요한 역할을 합니다.
