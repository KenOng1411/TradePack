Fomo Trading Fees Explained: Spot vs. Perpetuals, With Referral Code Savings

TradePack Team·September 29, 2026

Fomo’s fees aren’t hidden exactly, but they’re not posted in one obvious place either — so here’s the full picture in one spot.

Spot trading fees

Spot trades (memecoins, altcoins, stablecoins) cost roughly 0.5% per trade before any discount. Apply a valid referral code at signup and that drops by 10%, bringing the effective rate to about 0.45%. On very small trades, the effective cost can feel higher than the headline percentage suggests, simply because there’s often a practical minimum cost per trade — worth factoring in if you tend to trade in small increments frequently rather than in fewer, larger trades.

Perpetuals fees

Perpetuals run through an integration with Hyperliquid rather than being a self-contained Fomo product. Fomo adds roughly 0.05% per side on top of whatever Hyperliquid’s own underlying fee is for that trade — which in practice roughly doubles the direct cost of trading perps through Fomo compared to trading spot. Perpetuals are not currently available to US-based users; if that’s you, this section is more “for context” than something you’ll actually encounter in the app.

What a referral code actually saves you

Here’s the math in plain terms, using the 0.5% spot rate as the baseline:

Trade size Fee without code (0.5%) Fee with code (10% off → 0.45%) You save
$100 $0.50 $0.45 $0.05
$1,000 $5.00 $4.50 $0.50
$10,000 $50.00 $45.00 $5.00

The savings scale linearly with trade size — it’s a straightforward 10% reduction off whatever your fee would otherwise be, applied automatically on every trade once the code is attached to your account at signup. For an interactive version, use our fee calculator.

Costs a referral code doesn’t touch

Two things a discount code has no effect on: on-chain network fees (gas), which vary by chain — Solana, Base, BNB Chain, Monad — and by network conditions at the time of your transaction; and, for perpetuals, Hyperliquid’s own underlying fee, since Fomo’s discount applies to Fomo’s fee layer, not the venue fee sitting beneath it.

The bottom line

For spot trading, a referral code is a straightforward, no-downside 10% discount with no extra steps beyond entering it at signup. For perpetuals, the bigger factor in your total cost is the roughly 0.05%-per-side Fomo markup over Hyperliquid’s own fees — worth knowing about regardless of whether you’re using a referral code, especially if you trade perps frequently or at size.
