Häufige Fragen

Ist dieser Empfehlungscode offiziell?
Nein — TradePack ist eine unabhängige Testseite. Es handelt sich um den regulären Fomo-Empfehlungscode, kein exklusives TradePack-Angebot; Fomo unterstützt oder sponsert diese Website nicht.
Entstehen durch die Nutzung des Codes zusätzliche Kosten?
Nein. So funktioniert Fomos reguläres Empfehlungsprogramm — Sie erhalten 10% Rabatt, TradePack erhält möglicherweise eine Provision aus Ihren Handelsgebühren.
Kann ich den Code nutzen, wenn ich schon ein Fomo-Konto habe?
Empfehlungscodes gelten in der Regel nur bei der Registrierung — eine nachträgliche Eingabe wirkt meist nicht rückwirkend. Maßgeblich sind die aktuellen Regeln in der Fomo-App.
